# AWS S3 Bucket Structure

This document outlines the organization of objects within the AWS S3 bucket for the application.

## Bucket Policies

- **Access:** Private by default.
- **Public Read:** Specific folders (like `badges/` or public `profiles/` avatars) may be served via CloudFront/CDN with public read access.
- **Uploads:** Performed via Pre-signed URLs generated by the backend API.

## Directory Layout

### 1. User Profiles

Stores user-specific assets like avatars and cover photos.

**Pattern:** `profiles/{userId}/{filename}`

- `profiles/{userId}/avatar_original.jpg`
- `profiles/{userId}/avatar_400x400.jpg` (Processed/Resized)
- `profiles/{userId}/cover_original.jpg`

**Example:**
`profiles/60d5ec49f1b2c8b1f8e4e1a1/avatar_1698345678.jpg`

### 2. Task Proofs

Stores media uploaded as proof of task completion.

**Pattern:** `proofs/{userId}/{taskId}/{proofId}/{filename}`

- `proofs/{userId}/{taskId}/{proofId}/original.{ext}`
- `proofs/{userId}/{taskId}/{proofId}/thumbnail.jpg` (for videos/images)

**Example:**
`proofs/60d5ec49f1b2c8b1f8e4e1a1/60d5ec49f1b2c8b1f8e4e1b2/60d5ec49f1b2c8b1f8e4e1c3/original.mp4`

### 3. Badges (System Assets)

Stores badge icons and system graphics.

**Pattern:** `assets/badges/{badgeKey}/{filename}`

- `assets/badges/early_bird/icon_full.png`
- `assets/badges/early_bird/icon_small.png`

**Example:**
`assets/badges/streak_master/gold_medallion.png`

### 4. Community Assets

Stores community avatars and banners.

**Pattern:** `communities/{communityId}/{filename}`

- `communities/{communityId}/avatar.jpg`
- `communities/{communityId}/banner.jpg`

## Lifecycle Policies

- **Temp/Staging:** A `temp/` directory can be used for uploads in progress, with a lifecycle rule to expire objects older than 24 hours.
